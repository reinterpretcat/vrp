How to read the GSOM state
VRP edge footprintThe compact left surface aggregates directed edges over stored solutions. Peak height is the number of population members using an edge; axes are location indices, not geography.
Objective planesBest stored fitness at each occupied node. White cells have no stored solution.
Map distanceAverage feature distance to neighboring nodes. High values often separate regions of the learned topology.
Fitness basinsColor groups nodes reaching the same map-local minimum; arrows show steepest descent and lighter cells are farther uphill. A red cross is only a map-local sink proxy.
Total / recent hitsLong-term training usage versus activity in the current hit-memory window.
Node errorLocal quantization error. The caption also reports network-wide MSE and current learning rate.
Inactive snapshotDuring exploitation Rosomaxa no longer trains GSOM, so the last exploration map is shown and marked inactive.
